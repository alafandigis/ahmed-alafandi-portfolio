# Ahmed Alafandi GIS Portfolio — V2.0
Static bilingual HTML/CSS/JavaScript website.

Files:
- index.html — website structure and bilingual content
- style.css — Premium Corporate navy/gold responsive design
- script.js — language switch, RTL/LTR and mobile navigation
- assets/geospatial-earth.svg — original vector Earth illustration

Before public launch:
1. Verify biography and every project description.
2. Replace project themes with documented work, verified maps, dates, your role, tools and outcomes.
3. Add the professional email and LinkedIn URL you want public.
4. Add only web maps that are verified and approved for public sharing.
5. Add a CV PDF only after checking its public content.

Safe deployment:
1. Keep the current `main` branch unchanged.
2. Create a new branch named `v2-development` from `main` in GitHub.
3. Switch to `v2-development` and upload these files to the repository root (keep `assets/`).
4. Commit to `v2-development`.
5. Preview and test desktop/mobile and both languages.
6. Merge to `main` only after approval. Cloudflare Pages production should remain set to `main`.
